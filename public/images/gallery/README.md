# Фото для галереи

Кадры работ и мастерской, использованные в галерее (`src/data/gallery.js`):
файлы `g1.jpg` … `g8.jpg`. Подписи и размер плитки (`span`: `tall` / `wide`
/ `normal`) задаются в `gallery.js`.

Чтобы заменить кадр — положите файл с тем же именем. Можно использовать
вертикальные и горизонтальные фото, раскладка masonry подстроится.
