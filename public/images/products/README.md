# Фото товаров

Здесь лежат фотографии работ, использованные в карточках товаров
(`src/data/products.js`, поле `image`):

- `vase-silver.jpg` — Ваза «Серебро»
- `vase-night.jpg` — Ваза «Ночь»
- `candle-flowers.jpg` — Подсвечники «Цветы»
- `lamp.jpg` — Светильник «Свет»
- `plates.jpg` — Тарелки «Про себя»
- `candle-casanier.jpg` — Подсвечник (серия ST.CASANIER)

Чтобы заменить фото — положите файл с тем же именем. Имена задаются в
`products.js`. Рекомендуемый формат: квадрат ~1000×1000 px, .jpg/.webp.
