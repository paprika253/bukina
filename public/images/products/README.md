# Фото товаров

Положите сюда фотографии изделий. Имена файлов должны совпадать с полем
`image` в `src/data/products.js`, например:

- `mug-morning.jpg`
- `bowl-sand.jpg`
- `vase-dune.jpg`
- `plate-clay.jpg`
- `cup-pair.jpg`
- `incense-stone.jpg`

Рекомендуемый формат: квадрат, 1000×1000 px, .jpg/.webp. Пока файла нет —
на сайте показывается аккуратная заглушка.
