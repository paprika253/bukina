# Liza Bukina — сайт-портфолио керамики

Одностраничный сайт для мастера керамики и изделий ручной работы. Собран на
**React + Vite**. Разделы: **О себе**, **Товары**, **Галерея** + контакты.

> Контент (фото, тексты, материалы, цены) взят из публичного профиля
> [instagram.com/liza.bukina](https://www.instagram.com/liza.bukina/): реальные
> работы (вазы, подсвечники, светильник, тарелки), подписи и контакты. Фото
> лежат в `public/images/`. Если файл по какому-то пути отсутствует — на его
> месте автоматически показывается аккуратная керамическая заглушка.

## Запуск

```bash
npm install      # установка зависимостей
npm run dev      # локальный сервер разработки (http://localhost:5173)
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр собранной версии
```

## Как наполнить своим контентом

Весь контент вынесен в простые файлы данных — править код не нужно.

| Что меняем | Файл |
|---|---|
| Имя, роль, контакты, тексты «О себе», факты, навыки | `src/data/site.js` |
| Карточки товаров (название, описание, цена, статус, фото) | `src/data/products.js` |
| Галерея работ (заголовок, фото, размер плитки) | `src/data/gallery.js` |

### Добавление фотографий

1. Фото товаров → `public/images/products/` (имена как в `products.js`).
2. Фото галереи → `public/images/gallery/` (`g1.jpg` … `g8.jpg`).
3. Портрет мастера → `public/images/about/portrait.jpg`.

Как только файл появляется по нужному пути, он автоматически заменяет заглушку.

### Статусы товаров

В `products.js` у каждого товара поле `status`:
`in_stock` (В наличии) · `made_to_order` (Под заказ) · `sold` (Продано).

## Дизайн

Тёплая «глиняная» палитра (терракота, песок, крем, шалфейный акцент),
шрифты Cormorant Garamond + Manrope. Адаптив, мобильное меню, лайтбокс в
галерее с навигацией стрелками и клавишами ←/→/Esc. Вся дизайн-система —
в `src/styles/index.css` (CSS-переменные в `:root`).

## Деплой

Статическая сборка `dist/` разворачивается на любом хостинге (GitHub Pages,
Netlify, Vercel). Для GitHub Pages в подкаталог укажите `base` в
`vite.config.js`.

## Структура

```
src/
├─ components/   # Header, Hero, About, Products, Gallery, Footer, SmartImage
├─ data/         # site.js, products.js, gallery.js — весь контент здесь
├─ styles/       # index.css — дизайн-система
├─ App.jsx
└─ main.jsx
public/
└─ images/       # сюда кладём реальные фото (products / gallery / about)
```
